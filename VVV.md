## 🚀 How to Use the Console CLI (`VVV.py`)

The console CLI (`VVV.py`) provides an interactive, multi-stage compilation pipeline with real-time percentage progress bars, SIMD/WebGL hardware probing, and BSON binary packaging.

### Option 1: Interactive Console Mode (Recommended)
Simply launch `VVV.py` without arguments from your terminal:
```bash
python VVV.py
```
1. The CLI displays the high-tech ASCII banner, system credentials, and architectural vision matrix.
2. It auto-detects default slide directories (`./slides` or `./release/slides`).
3. Press **Enter** to accept the detected directory, or type a custom path to your slide images.
4. Watch the 5-stage real-time build pipeline compile your standalone WebGL presentation!

### Option 2: Command Line Argument Mode
You can pass custom paths directly via terminal flags:
```bash
python VVV.py --slides ./my_slides_folder --out vvv_custom.html
```

#### CLI Flags:
* `--slides <path>` : Path to directory containing input slide images (`.png`, `.jpg`).
* `--out <filename>` : Output standalone HTML filename (Default: `vvv_test.html`).
